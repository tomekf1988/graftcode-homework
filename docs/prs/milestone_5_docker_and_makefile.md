# PR — Milestone 5: Docker, Docker Compose, Makefile

## Summary

- **Only pricing-graft runs in Docker.** `docker compose up -d` starts a single `pricing-graft` container (ports 80/81). The order service runs locally via `uv run --project order_service`.
- **New `Makefile`** with three targets: `setup` (install deps + graft package), `test` (pytest), `run` (start both services).
- **`pyproject.toml` and `uv.lock` moved** from repo root to `order_service/` — there is only one Python package.
- **`pricing_service/graft/pyproject.toml` added** — required by the `gg` GMA (module analyzer) to extract Python metadata.
- **Graft package updated** to `graft-pypi-pricing-service-graft==0.1.0` (new URL generated by `gg` on first successful startup). Registry documented in `order_service/pyproject.toml` via `[[tool.uv.index]]`; installed separately in `make setup` because the registry is not PEP 503-compliant.
- **Deleted:** `main.py` (dead smoke-test), root `pyproject.toml`, root `uv.lock`, `order_service/Dockerfile` (order service no longer containerised).
